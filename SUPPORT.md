# Support

Read [First run](docs/FIRST-RUN.md), [Recipes](docs/RECIPES.md), [Safety](docs/SAFETY.md), and [Troubleshooting](docs/TROUBLESHOOTING.md) first.

For reproducible module defects, open a [GitHub issue](https://github.com/avalonreset/legends-obs/issues) with the `legends-obs` version, Windows version, OBS Studio version, Node.js version, sanitized `doctor --pretty` output, and expected behavior. Never post OBS WebSocket passwords, stream keys, service credentials, recordings, or unredacted local paths.

General OBS Studio bugs, GPU driver issues, and streaming platform incidents belong with their respective upstream support channels. Recording and profile changes remain the operator's responsibility. Community support has no guaranteed response time.
